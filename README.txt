DRSTNITRO V2 — DEVELOPER PORTFOLIO

MENJALANKAN
1. Ekstrak ZIP.
2. Buka index.html di browser atau unggah seluruh folder ke hosting statis.
3. File banner.mp4 sudah disertakan di folder yang sama dengan index.html. Video mencoba autoplay dalam keadaan mute; tekan tombol Aktifkan suara setelah dashboard terbuka untuk menyalakan audio (kebijakan browser).
4. Edit config.js dan isi whatsappNumber dengan nomor WhatsApp format internasional tanpa + atau spasi.

FITUR
- Intro WELCOME dan NEXT.
- Fingerprint adalah simulasi UI: tekan dan tahan 8 detik; melepas atau keluar dari area sebelum selesai mereset progres.
- Transisi INITIALIZING... lalu WELCOME, DEVELOPER.
- Dashboard responsif: sidebar desktop dan drawer mobile.
- Home, Projects, Services, About, Contact, Skills, Terminal / Developer Info, Experience.
- Projects memakai aset proyek yang ditemukan di source, dengan pencarian, filter kategori, dan halaman detail. Link demo tidak dibuat-buat.
- Services memiliki Learn More dan Discuss Project.
- About menggunakan thumbnail.jpg serta galeri foto dari aset source dengan lightbox.
- Video banner dipindahkan dari intro ke topbar dashboard, sehingga satu elemen video tetap dipakai saat navigasi. Rasio video dijaga dengan object-fit: contain.
- Terminal hanya simulasi aman, tidak mengeksekusi perintah sistem.
- Form Contact menyiapkan pesan WhatsApp; tidak mengirim pesan otomatis.

CATATAN ASET
- banner.mp4 disertakan dan dipakai sebagai banner video. Autoplay bersuara tidak dijamin browser; audio memerlukan tap pengguna. Musik terpisah tidak dipakai.
- thumbnail.jpg adalah foto profil yang digunakan di sidebar dan About.
- Data profil, tautan, dan nomor kontak yang belum tersedia tidak dikarang.
- Situs ini statis, tidak memerlukan database, login admin, atau backend.

REDESIGN V2
- Neo-brutalist interface dengan tema Cream, Blue, dan Dark.
- Pilihan tema tersimpan lokal di browser.
- Animasi/transisi tetap menghormati prefers-reduced-motion.
